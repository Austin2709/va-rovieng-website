## Troubleshooting Quick Fixes

### "Git is not recognized"
- Restart your computer after installing Git
- Open a new Command Prompt window

### "Fatal: not a git repository"
- Make sure you're in the correct folder
- `cd "C:\Web VA ROVIENG CO\va-rovieng-website"`

### "Authentication failed"
- GitHub now requires a Personal Access Token
- Generate one at: https://github.com/settings/tokens
- Use it as your password when prompted

### "Push rejected"
- Run: `git pull origin main --allow-unrelated-histories`
- Then: `git push origin main`

**→ More help? Read GITHUB_SETUP.md (Troubleshooting section)**
